# Submit checklist

Source: the 2026 Project Submission Guide and Judging & Awards Guide (see `SUBMISSION_REQUIREMENTS.md`). Tick each box before clicking "Submit for Judging". Real deadline: Sunday Nov 15, 11:59 p.m. Local Event time. Internal target: 9 PM.

## Team and eligibility
- [ ] Team has at most 6 members, all on the Members tab
- [ ] Every member is registered at the same Local Event and is not waitlisted
- [ ] Project responds to the official challenge "Be An Earth System Trend Detective"

## Project page (every required field filled, all in English)
- [ ] Project Name
- [ ] High-Level Project Summary
- [ ] Link to Project Demo (public, opens in a private window)
- [ ] Link to Final Project (public, opens in a private window, no login)
- [ ] Detailed Project Description (what it does, how it works, benefits, goals, tools)
- [ ] Use of Super Intelligence (SI): answered, and the idea's origin stated accurately
- [ ] NASA Data: MERRA-2 collections named
- [ ] Space Agency Partner Data and Other References: every library, font, image, text and code source listed, even open source
- [ ] Two checkboxes ticked: Terms and Conditions, and "Confirm All Work is Original"

## Demo
- [ ] Video of 30 seconds or less (check the exported file), OR deck of 7 slides or fewer
- [ ] Hosted publicly (YouTube, Drive, etc.), no password or sign-in
- [ ] Deck shows team name, member names and the challenge; or video introduces the team and challenge
- [ ] English, or English subtitles on a non-English video
- [ ] No one under 18 appears or is heard

## Content rules
- [ ] No NASA logos, flags or mission identifiers anywhere
- [ ] Generated images and video have a visible SI watermark; generated audio acknowledged in text and metadata
- [ ] Code and data written with SI are acknowledged in descriptive text and metadata (folder READMEs, commit trailers, site footer)
- [ ] No copyrighted music, images or text we lack permission to use

## Final checks
- [ ] Site loads from the public URL on a second machine and network
- [ ] `node content/validate.mjs` passes
- [ ] `VALIDATION.md` filled with real numbers and an honest result statement
- [ ] Real numbers added to the narration (table in `DEMO_SCRIPT.md`)
- [ ] Optional: FortiGuard Web Filter Classification requested for the site
- [ ] "Submit for Judging" clicked, success banner seen, certificate available on the profile
